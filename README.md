# Scooty Charge 🛴

## About

Scooty Charge is a project developed to simulate the management of an electric scooter charging station.

The desktop application was developed using C and GTK4, with a focus on practising programming fundamentals and building graphical user interfaces.

The project also includes work with MIT App Inventor as part of its development.

## Project Goals

- Simulate the management of an electric scooter charging station.
- Explore desktop application development.
- Practise programming in C.
- Build graphical interfaces using GTK4.

## Technologies

- **C** – Main programming language for the desktop application.
- **GTK4** – Graphical user interface toolkit.
- **CSS** – Interface styling.
- **MIT App Inventor** – Mobile application development environment.

## Project Structure

- `headers/` – Header files.
- `src/` – Source code.
- `imgs/` – Image resources.
- `main.c` – Main application entry point.
- `style.css` – Interface styling.

## Getting Started

### Requirements

- A C compiler.
- GTK4 development libraries.
- A development environment compatible with GTK4.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/X1Gms/Scooty_Charge.git
   ```

2. Open the project folder:

   ```bash
   cd Scooty_Charge
   ```

3. Install the required GTK4 dependencies for your operating system.

4. Configure the project using your preferred C development environment.

5. Build and run the application.
